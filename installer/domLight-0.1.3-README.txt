This supersedes 0.1.0 and 0.1.2 network installers. It includes all 922 packages required by this desktop and the Fedora core package group, plus local repository/group metadata. OPTIONAL: REPAIR THE EXISTING INSTALLATION WITHOUT REINSTALLING

After writing the new image to USB, plug it into the installed PC while logged into the text console. Ensure this is the 0.1.3 USB, not the old installer. Run:

sudo mkdir -p /mnt/domlight
sudo mount -o ro /dev/disk/by-label/Fedora-E-dvd-x86_64-44 /mnt/domlight
ls /mnt/domlight/domLight-package-manifest.json
sudo dnf --disable-repo='*' --repofrompath=domlight-usb,file:///mnt/domlight --setopt=domlight-usb.gpgcheck=1 install realtek-firmware alsa-sof-firmware intel-audio-firmware intel-gpu-firmware linux-firmware-whence kernel kernel-modules kernel-modules-extra pciutils usbutils rfkill
sudo reboot

Only continue if the manifest file exists. If USB auto-mounted already, use its actual mount path instead of /mnt/domlight. Fedora may request confirmation to import its official signing key. This installs from USB without internet and does not erase user files. It may update the kernel and its dependencies.

After restarting, connect Wi-Fi:
nmcli device wifi list
sudo nmcli --ask device wifi connect "Your WiFi Name"

If the graphical login still fails, use the temporary text-console boot method and collect:
systemctl status sddm --no-pager -l
sudo journalctl -b -u sddm --no-pager -n 60
sudo journalctl -b -k --no-pager | grep -Ei 'i915|drm|firmware|failed'
